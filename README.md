## DISCLAIMER
Each feature in this mod can be used independently from each other, meaning that, if you want to use a single specific feature of the mod (*CS*, *PET*, or *Music Pack*), then simply disable either one or both of these required mods:

* [**Character Select**](https://mods.sm64coopdx.com/mods/character-select.149/) (For **[CS] Now or Never Seven**) | @Squishy6094
* [**WiddlePets**](https://mods.sm64coopdx.com/mods/widdlepets.209/) (For **[PET] Smallfry Salmonid**) | @wibblus

This mod will only work properly if you have the latest version of Character Select *(v1.16 onwards, preferably v1.16.3)* + the current version of SM64 Co-op DX *(v1.4 onwards, preferably v1.4.1)*.

## FEATURES
* **[CS] Now or Never Seven**
  * *Callie, Marie, Pearl, Marina, Shiver, Frye, & Big Man* are included, all recolorable!
  * Costumes based on *Agents 1 & 2*, *Octo Expansion*, and **Raiders**, including an extra *Hypnoshade* costume for Callie!
  * Swim forms, with an added replica of **Super Mario Sunshine**'s diving move as a moveset option for swimming like a Squid!
  * An overhaul on the game's HUD to match the *Splatoon* style.
  * Compatibility with the *"[So Retro!](https://mods.sm64coopdx.com/mods/so-retro.666/)"* mod, including an accurate color palette option!
* **[PET] Smallfry Salmonid**
  * All **Splatoon 3** hairstyles are included as alts.
* **SplatIdols 64 Music Pack**
  * Featured songs:
    * **Calamari Inkantation 64MIX** - Replaces *"Ultimate Koopa"*
    * **Onward! (N64)** - Replaces *"Course Clear"*
  * Unique songs for *Caps/Keys* for **[CS] Now or Never Seven**.
  * Options for toggling *Custom Music* **[ON/OFF]**, **[ON]** by default.

## SPECIAL "TEAM" COLORS TUTORIAL
Want to know a neat trick for getting custom "team" colors on your idol without having to recreate the entire palette?
* Select *"Save Active Palette as Preset"* in the Player options menu.
* Give it a preset name of your own.
* In *"Edit Palette"*, edit colors as you please.
* Once done, select *"Save Preset"*.
* Boom, now you've got your own colors!
